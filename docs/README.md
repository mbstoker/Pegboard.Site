# Pegboard.Site Docs

## Purpose

These are tactical docs for the public marketing site at epegboard.com. They live beside the site code so implementation notes, redesign decisions, and deployment context stay close to the app they describe.

## What belongs here

- Public-site feature and redesign notes.
- Site map, content, and conversion-flow planning.
- Repo-local deployment or QA notes for the marketing site.
- Mockups and screenshots used to validate site changes.

## What does not belong here

- Growth outreach waves. Put those in `../../../Marketing/Outreach/`.
- General social/community strategy. Put that in `../../../Marketing/SocialMedia/`.
- Venture strategy. Put that in `../../../Strategy/`.
- Customer-facing help docs. Put those in `../Pegboard.Docs/`.

## Source-of-truth notes

This repo owns tactical truth for the marketing site. Growth backlog state lives in HQ Postgres areas `Marketing` and `Site-Dev`.
